# iOS 长页面分区导航

采用标准原生风格，以快速查阅内容为目标。固定于滚动区域上方的系统分段选择器支持直接切换；辅助字号使用上下排列的菜单，避免标签压缩。

| 页面 | 分区 |
| --- | --- |
| 精灵详情 | 概览、技能、进化、介绍 |
| 精灵技能 | 技能池、技能石、血脉技能 |
| PVP 助手 | 双方构筑、能力比较、对战分析 |
| 伤害与一击线 | 伤害计算、属性关系、一击线 |
| 技能详情 | 技能资料、获得方式 |

切换后内容回到开头，短介绍也能贴近顶部显示。精灵头像保留在同一个滚动视图中，保持共享图片返回转场的注册关系。技能筛选、获得关系筛选、双方临时构筑及伤害条件由页面持有，切换分区不会清空。技能列表提供两行说明摘要，点按可打开全文；辅助字号保留完整说明。尚未选择双方精灵时，PVP 比较和分析页提供返回构筑的按钮。

实现涉及 `PetDetail.swift`、`PVPBattleView.swift`、`SkillsView.swift`、`SkillAcquisitionResultsView.swift`、两个共享视图 `CompanionTabBar.swift` / `CompanionTabbedPage.swift`，以及项目源文件注册和相关 UI 测试。

## 验证

- Xcode 27.0 / Swift 6.4，RocoNative 模拟器构建通过。
- iPhone 18 Pro，iOS 27.0：九项不同的定向 UI/host 测试均在对应最终检查中通过。覆盖长页滚动后切换、短分区顶部定位、精灵与获得关系筛选保留、PVP 重复切换与准备状态、进入伤害页后返回原分区、伤害技能选择保留、关联精灵跳转、共享图片一致性及滚动详情返回图鉴位置。
- 检查浅色、深色、普通字号、最大辅助字号；最大辅助字号下菜单能选择精灵分区及技能来源。伤害和大字体测试同时使用已有的 Reduce Motion 测试入口。新分区切换不添加自定义动画，导航背景使用不透明系统色。
- SwiftUI 静态扫描：30 个文件，0 个高风险、39 个中风险提示。提示包括已有的 GeometryReader、固定图标尺寸和索引身份等；新共享视图未出现扫描提示。
- `git diff --check` 通过。

结果保存在 `build/ios27-p0/quick-sections*.xcresult`；图片保存在 `build/ios-parity/quick-sections-{light,dark,accessibility,preview}/`。首次旧返回测试以首页作为图鉴入口失败，更新入口后还发现 XCTest 自动滚动了部分可见的源卡片；测试现先将卡片滚到可点位置，再记录坐标，最终返回检查通过。早期失败的结果包保留，不视为通过。
