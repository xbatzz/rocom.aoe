# iOS 功能修改勾选清单

请将需要修改的项目从 `[ ]` 改成 `[x]`。也可以直接回复编号，例如“D04、S01、T01”。

**只实施打勾的项目；留空的项目不修改。所有项目默认未选。**

每项包含实现该功能必需的数据接入、保存/备份兼容和验证；不因技术依赖而自动开启其他未选功能。新增功能包含对应的正式入口。若标记后继续改选，以你的最新选择为准。

详细依据见 [功能审查报告](./ios-web-feature-parity-audit.md)。这份清单用于选择范围；勾选项的实施结果见 [逐项实施记录](./ios-selected-implementation.md)，勾选本身不表示完成状态。

- [ ] **D01** 图鉴增加“全部 / 已实装 / 未实装”筛选，覆盖当前内容包中的有效配置。
- [ x] **D02** 图鉴增加“具有首领潜力”筛选。
- [ ] **D03** 图鉴支持输入血脉技能名称查找精灵。

- [ x] **D05** 精灵详情的技能池、技能石支持名称/描述、属性、类别筛选和重置。
- [ x] **D06** 点击精灵详情中的技能，可进入该技能的详情和可获得精灵反查。
- [ ] **D07** 精灵详情显示已有捕捉原始信息：阈值、保证率、球等级及缺失提示。
- [ ] **D08** 精灵详情增加 Web 的捕捉难度、球推荐、预计次数及说明。
- [ ] **D09** 精灵详情增加攻击倾向、最高种族值、技能覆盖属性和技能分类数量摘要。
- [ x] **D10** 新增高级筛选：属性、指定技能及来源、攻击倾向、阶段、实装状态组合查询，六维和总种族值升降序排序。
- [ ] **D11** 精灵详情补充区域、刷新地点等完整分布资料。
- [ ] **D12** 精灵详情显示进化等级、条件文字及材料要求；需要材料名称时接入必要目录，但不自动增加道具页面。
