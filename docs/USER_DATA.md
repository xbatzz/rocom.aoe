# 用户数据备份与迁移

## 存储范围

用户数据只保存在当前浏览器的 `localStorage`，不写入 `public/data`，也不会随 GitHub 或 Vercel 部署上传。

| 数据 | localStorage key | 说明 |
| --- | --- | --- |
| 配队 | `rocom.team-builder.v2` | 多队伍、当前队伍、精灵、性格、血脉、个体值、技能和血脉魔法 |
| 图鉴进度 | `rocom_handbook_progress` | 已收集精灵和图鉴课题完成时间 |
| 八大徽章 | `rocom.badge-trials.v1` | 各属性家族奖牌与地点精灵足迹完成时间 |
| 主题 | `rocom.theme.v1` | 浅色或暗色主题 |

不同设备、不同浏览器配置文件以及 Safari/Chrome 之间不会自动共享这些数据。

## 完整备份

访问 `/data-management`，点击“下载完整备份”。文件名格式为：

```text
rocom-user-data-YYYYMMDD.json
```

备份格式：

```json
{
    "format": "rocom-user-data",
    "version": 2,
    "exportedAt": "2026-07-31T00:00:00.000Z",
    "data": {
        "teams": {},
        "handbookProgress": {},
        "badgeTrials": {},
        "theme": "dark"
    }
}
```

备份仅包含工具箱中的构筑、图鉴/徽章进度编号和界面设置，不包含游戏账号、密码或登录凭证。

## 跨设备迁移

1. 在原设备打开“数据管理”并下载完整备份。
2. 将 JSON 保存到 iCloud Drive、网盘、隔空投送或其他可信文件位置。
3. 在新设备使用同一站点打开“数据管理”。
4. 选择备份文件并使用“完全替换”恢复；如果新设备已经有数据，使用“合并”。
5. 导入成功后页面会自动刷新，使配队页、PVP、图鉴进度和八大徽章读取新数据。

## 合并规则

- 配队以稳定的 `team.id` 为键；相同 ID 保留 `updatedAt` 较新的版本，不同 ID 的队伍都会保留。
- 图鉴收集和课题完成记录使用已有时间戳合并逻辑，每一项保留较新的完成时间。
- 徽章家族奖牌和地点足迹按稳定 ID 与完成时间戳合并，每一项保留较新的完成时间。
- 当前设备的激活队伍在“合并”模式下保持不变。
- 主题采用备份中的设置。

“完全替换”会用备份覆盖当前设备的全部配队、图鉴进度和徽章进度。执行替换前建议先导出一次当前数据。

## 版本与兼容性

- 完整备份当前版本为 `2`；版本 `1` 仍可导入，导入时补充空徽章进度。
- 配队内部格式为 `rocom.team-builder.v2`；旧的 `rocom.team-builder.v1` 仍由配队存储模块自动迁移。
- 无法识别的格式或版本会在写入前被拒绝，不会部分导入。

## 当前边界

当前功能属于手动备份与迁移，不是云同步。多台设备同时修改后，需要在其中一台设备导出，再到另一台设备选择“合并”。未来接入账户同步时，可以继续复用本备份格式作为恢复与迁移通道。
