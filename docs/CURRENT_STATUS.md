# 当前版本状态

本文记录个人版 `rocom.aoe` 的当前改造状态，用于后续 Codex 新窗口快速接续。

## 当前已完成

- 首页个人版入口：首屏聚焦属性克制、图鉴搜索、技能搜索和轻量对战助手，并保留“更多工具”区域。
- 全局导航：侧边栏保留原项目功能入口，并新增正式 `/skills` 技能入口。
- 属性页优化：`/attributes` 已从圆形图谱优先改为四象限信息卡优先，图谱保留为辅助视图。
- 双属性防守面：支持两个不同属性组合的 3x、2x、0.5x、0.25x 与普通承伤分组。
- 双属性打击面：展示两个技能属性分别 2x 克制的目标，以及合并后的打击覆盖。
- 排除“首领”血脉：属性页、属性选择器、图谱、防守面和打击面均不把“首领”作为普通战斗属性。
- `/skills` 技能查询与反查：支持技能名称、ID、描述、属性、分类搜索；技能详情可按来源、精灵关键词、属性、实装状态和展示方式筛选可获得该技能的精灵。
- 完整技能目录：`PetSkillIndex.json.skills` 由 `SKILL_CONF` 生成名称、图标、属性、分类、描述、能耗和威力，`#7000341` 及后续新技能不再依赖旧版 `moves.json` 才能显示详情。
- 技能图标与重复技能合并：`/skills` 复用 `SkillIcon.vue`；同名但不同 ID 的技能会合并，技能数值和描述优先采用 `PetSkillIndex` 的当前游戏配置，`moves.json` 仅保留短 ID、英文名和缺失技能兜底。
- 技能获得索引：`SkillAcquisitionIndex.json` 汇总自有技能、技能石和血脉技能，并保留同名技能的关联 ID；`yarn test:skill-acquisition` 校验正反索引一致性。
- 精灵家族口径：技能反查默认只显示已实装、非首领的最终进化形态，同一最终图鉴形态视为一个家族；技能卡片数量与详情默认结果一致。
- PWA 第一版：新增 manifest、主屏幕图标和 service worker，支持应用壳、核心路由与核心 JSON 的基础离线缓存。
- 统一数据管理：`/data-management` 支持完整导出和导入配队、图鉴进度、徽章进度、主题设置，提供合并与替换两种恢复模式。
- 八大徽章：`/badge-trials` 已支持草系家族奖牌点亮、宫格/列表与分页切换，以及三个试炼地点的一般/地区/首领形态精灵足迹搜索、家族全阶级联想、已点亮/未点亮手动录入和状态/形态组合筛选。
- 对战助手：`/pvp-lite` 支持双方选择、当前构筑六项实战属性对比、本系克制倍率、当前队伍联防候选、双向技能伤害、六项种族值和特性查询；手机与桌面通过五项任务标签切换。
- 核心页面移动端整改：图鉴与技能采用搜索优先和按需筛选，属性页压缩属性选择，配队槽位打开移动构筑面板，对战助手按当前任务渐进展示。
- 全局导航分层：一级导航只保留核心工具、资料与收集、培育工具，数据管理固定在系统区域；查蛋和蛋组关系通过培育模式导航进入。

## 当前核心页面

- `/attributes`：属性克制、单属性四面、双属性防守面、双属性打击面。
- `/encyclopedia`：图鉴查询与宠物详情入口，移动端搜索优先并按需展开高级筛选。
- `/skills`、`/skills/:id`：技能百科、可获得精灵反查和家族筛选。
- `/pvp-lite`：移动端与桌面端共用的对位入口，聚焦当前构筑属性、克制、联防、伤害和资料。
- `/table`：高级组合筛选；桌面显示可排序表格，手机显示精简结果卡。
- `/badge-trials`：草系徽章家族奖牌与三个地点的手动精灵足迹记录。
- `/breeding`、`/incubate`、`/egggroup`：统一培育工具的三个连续模式。
- `/data-management`：本地用户数据完整备份、跨设备迁移和恢复。

## 注意事项

- 本项目统一使用 Yarn：常用命令为 `yarn install`、`yarn dev`、`yarn build`；技能数据更新后还要运行 `yarn test:skill-acquisition`，精灵数据更新后运行 `yarn test:badge-trials`。
- 不要手工修改 `public/data` 中的基础游戏数据。
- 不要修改 `scripts`，除非任务明确要求数据同步或脚本维护。
- 不要修改 `yarn.lock`，除非依赖相关任务明确要求。
- 个人改造优先放在 `src/features/*`、`src/custom` 或 `public/my-data`，降低同步上游时的冲突。
