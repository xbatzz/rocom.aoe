## 备份兼容

- Web 数据管理可导入 iOS 原生 v1/v2 备份，导出新版 Web v5 交换备份。
- iOS 支持新版 Web v5 与原生 v1/v2。旧 Web v1–4 继续走原有兼容路径；未勾选 U03，不扩大旧版本的激活范围。
- 取消、移除、独立偏好和队伍修改分别保留时间；时间冲突按较新记录合并，取消状态在同时间优先。
- Web 保留跨端缓存及原始 JSON 归档；不同平台暂不能显示的字段可随备份继续往返。
- 完整解析及校验在写入前进行；iOS 事务失败回滚，Web 写入失败恢复相关存储键的原始字节。重复导出同一内容不重复堆积归档。

可复现跨端测试：先运行 `node scripts/test-native-user-data-exchange.mjs`；设置 `ROCO_PARITY_DIRECTORY` 为仓库 `build/ios-parity` 的绝对路径后运行 RocoContent package 的 `swift test`；再运行 Web 测试脚本，核对 SwiftData 恢复后再次导出的文件。

运行证据存放在 `build/ios-parity/`（生成目录，不提交）。没有真机及真实游戏截图样本的验收结论；OCR 对不确定字段保留提示，必须逐槽确认。没有新增未勾选的技能别名合并、旧备份额外激活、新工具页面或基础游戏数据编辑。
