# iOS 与 Web 功能对齐审查及补全方案

审查日期：2026-10-03。代码基线：`169d654f0ad158427676d1e1b33656066a8d1e94`。

## 审查结论与边界

iOS 已具备图鉴、属性克制、技能、配队、PVP、异色、草系足迹、命定勇者及备份的真实实现，基础计算和持久化有测试支撑；但页面存在不代表与 Web 功能对齐。当前主要差距是技能查询口径、跨入口导航、PVP 对手与联防选择、草系家族奖牌、异色路线辨识、当前队伍及双向迁移。

本次逐项检查 `src/pages` 的 18 个路由页面、Web 功能组件/业务函数、iOS 正式入口及全部业务页面、RocoContent/RocoUserData、范围登记和实际打包内容。结论以当前源码为准，阶段文档只作背景，不把旧“待实现”记录当成当前状态。

这是代码和数据审查，未修改业务代码，未运行 Simulator/真机逐屏交互。下文“已实现”表示找到真实数据及调用路径；“缺失”表示当前数据模型、入口或调用链缺少对应能力；涉及界面表现的例子是根据源码和数据得出的静态结论，仍应通过后续 UI 验收。

历史范围来自 `shared/content/ios-scope.json` 与 `docs/ios-p1/scope-pruning.md`：只覆盖八项功能，道具、培育、课题、奖励、进化材料被明确裁剪。把它们纳入完整 Web 对齐，需要扩展产品范围和内容契约。本次仅提出方案，不擅自撤销已有裁剪。iOS 当前目标版本沿用仓库的 iOS 27，不在本方案中新增旧系统支持。

## 可执行的分批方案

### 第一批：修复核心结果与记录口径

1. S1：组查询、别名获得关系、具体 SkillID 的数值与计算边界。
2. D2：外部详情连续关系导航；缺图不能挡住资料。
3. B1/B3/A1：首领对手、指定属性联防、进攻被抵抗。
4. C4：3 组异色路线的名称/形态辨识。
5. T1/C1：当前队伍、草系家族奖牌独立模型。
6. U1/U2：在以上新状态确定后补双向交换和激活/归档预览。

前四项主体可复用已有内容，不需扩展基础游戏目录；第五项需用户库/备份迁移，第六项同时影响 Web 和 iOS，应该单独提交和验证。

验收：组别名查询结果一致；技能→精灵→进化连续可达；PVP 可选首领、正式配队仍拒绝；单属性与综合联防有明确不同结果样例；同代表异色槽可区分且状态互不影响；更新非当前队伍不改变首页/PVP 默认；家族奖牌不改变足迹或命定勇者；双方备份往返后所有已支持用户字段保持语义。

### 第二批：补齐日常查询和构筑效率

落实 D1/D3/D4 原值/D5/D6、S2/S3、A2 分别覆盖、T2/T3/T4、B2/B4/B5、C2/C5/C6；文本问答 B6 可单独提交。高级筛选先不接蛋组。图片导入 T5 独立交付，不能与普通构筑编辑混为一次大改。

验收：相同输入的候选集合、默认家族数、来源数及排序与 Web 基准一致；快捷预设不破坏最多三项个体/四招规则；未保存草稿关闭/切换仍受保护；所有搜索入口支持约定的编号与形态；录入、撤销、移除后重新启动/合并结果正确。

### 第三批：按完整工具范围扩展

先冻结 X1 范围与新 schema，再分两条依赖链逐项实施：

- 培育字段 → 详情培育 → 配种/查蛋 → 蛋组列表 → 高级筛选蛋组。
- 图鉴收藏 → 课题目录和记录；道具/配方目录 → 进化条件及奖励关联 → 课题完整奖励展示。

每步完成 exporter、validator、determinism、DTO/FK、业务 fixtures、用户迁移与真实界面，才能增加正式入口。不要一次导出全部 BinData 来替代按功能证明所需字段。

### 第四批：展示偏好与发布体验

命定列表、关系图谱、拖动排序、语音问答、主题偏好、需要的深链接和内容更新策略。图谱必须有文本可达替代；语音失败仍可输入文字。延续 frozen 图鉴导航，不为增加这些入口重写已接受的共享头像转场。

## 验证与后续任务切分

- 查询和计算：从现有 Web 业务函数生成对照 fixtures，测试结果集合及字段，不写只镜像 Swift 实现的测试。新增重点是技能 group union、单属性联防、首领候选资格、预设与培育边界。
- 用户数据：磁盘关闭重开、未知 ID 保留、所有独立收集记录隔离、更新/取消合并、版本迁移失败回滚、双向格式交换、只归档字段可取回。
- UI：选择与返回、多个入口的详情关系、搜索清除、草稿保护、系统文件导入/分享、VoiceOver、最大辅助字号、浅深色和 Reduce Motion。现有 core tests 不能替代这些验收。

- 改跨端业务/交换 reader：`yarn type-check`、`yarn build` 加相应 focused tests，以及 Swift tests/quick iOS build。
